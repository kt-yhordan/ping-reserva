# Ping Reserva

Aplicacion web para gestionar reservas de mesas en un restaurante chifa.

## Integrantes

- Yhordan Yael Yaja Chambi
- Gerald Sebastian Tito Bautista
- Jhoan Fabricio Fabian Cisneros

## Descripcion

Esta aplicacion permite a los clientes ver las mesas disponibles y realizar reservas. 
Tambien tiene un panel de administrador donde se puede ver el estado de las mesas y un calendario de ocupacion.

## Tecnologias usadas

- React
- JavaScript
- CSS

## Como instalar y ejecutar el proyecto

1. Abrir la terminal en la carpeta del proyecto
2. Escribir el siguiente comando:

npm install

3. Luego escribir:


npm start


4. Abrir el navegador en:


http://localhost:3000



## Funcionalidades principales

- Ver mesas disponibles y VIP
- Reservar mesas
- Cambiar el estado de las mesas (Disponible, Ocupada, Reservada)
- Panel de administrador con lista de reservas
- Calendario simple de ocupacion
- Paginas de informacion del restaurante y contacto
